# 制作笔记 · Making of

这份记录的重点不是"做了什么"，而是**哪些做法试过、为什么被换掉**。图集本身是三小时的
反复，但踩过的坑是通用的：任何 Q 版 / 宽袖角色做动作帧都会遇到同一批问题。

## 角色与基准

白发（发梢淡紫）红瞳、黄色贝雷帽带金扣、左鬓红色 X 发饰、黄色宽袖羽织（钟形，垂到腰下）、
深紫内领、白珍珠项链、紫红碎花短裙、红腰带、白袜、红色厚底木屐。

- 立绘基准：`sources/walk/neutral.png`（侧面朝右，907×907）
- 坐姿基准：`sources/states/idle.png` 与 `sources/wait_sway/`（正面坐姿）

**所有帧都从基准图链式编辑**：第 N 帧作为第 N+1 帧的输入，绝不每帧回锚点重画——
否则六帧会变成六个不同的人（脸宽、发量、裙长全都会飘）。

## 走路：6 帧 → 4 帧 → 3 张图

第一版按教科书做 6 帧（接触 / 下沉 / 通过 / 接触 / 下沉 / 通过）。结果是**穿帮全出在两张「通过帧」上**：
膝盖内折、脚尖朝下、脚跑到身体前面、木屐翘成一个奇怪的角度。192 px 下这些错误极其显眼。

压到 **3 张图 / 4 个关键帧**：

```
contact_a（右腿前） → neutral（双腿并拢、双脚贴地、手臂垂直） → contact_b（左腿前） → neutral
每帧停 2 拍 = 8 格，neutral 复用两次
```

关键规律：**三张图必须同源**。先出一张干净的 `neutral` 当母版，两张接触帧都从它编辑——
腿的比例、膝盖高度、画风才一致。从各自的旧帧改出来的，动起来就是瘸。

另一条反直觉的：**侧视走路的两张接触帧剪影本来就该几乎一样**。面朝右时前脚永远在画面前方，
所谓"左右腿互换"只差哪条腿在前面被遮住。交替感靠**摆臂方向**和**经过帧的起伏**，不靠腿形。
逼模型画出"明显不同的另一侧腿"，它做不到，只会逼出畸形。

## 摆臂：为什么第一版是僵尸

指令里只写"只改腿"——模型就真的只改腿，手臂被冻在原位，走起来像僵尸。
而且宽袖角色的摆臂**不能用角度描述**：25° 在钟形袖上只挪 8~12 px 看不见，45° 就变成企鹅张翅膀。

两条替代办法：

1. **描述手的位置和遮挡关系**："前摆手压在裙子上"、"后摆袖甩到身体轮廓外、探到头发那侧"、
   "两手水平距离约 1.5 个腰宽"。位置比角度可执行。
2. **给正反例图**：把"幅度太大"的废稿和"幅度太小"的那版一起喂进去，说"取废稿幅度的 1/3"。

还有一个畸形要防：模型会**凭空多画一片袖子**（第三片悬浮袖）。自检项写死"画面里只能有两只袖子"。

## 坐等：前后倾 → 左右摇

先试的是"坐直 → 略前倾 → 前倾撑地 → 收回"四帧，还补了两张中间帧。结论是**更糟**：
前后倾方向必须有个"倾到位"的姿势撑着，腿和裙摆的透视还得跟着变，怎么调都僵。

换方向：**下半身不动，上半身和头左右摇**。理由——

- 坐姿支点在屁股，本来就该上身在动、下盘稳；
- 左右摇是对称周期运动，头能回到中立位，不需要"到位"姿势；
- 不改变腿和裙摆的透视，天然不穿帮。

实现不靠生成模型（它做不了这种小幅且必须绝对一致的摆动），而是**数值软变形**
（`scripts/make_wait_sway.py`）：绕腰部支点旋转，旋转强度按高度分——腰部以上 1、
腰部以下 0、中间只留 8% 身高的过渡带。预乘 alpha 再插值，避免边缘黑边。
峰值 ±8°，8 帧铺满一行。

> 渐变零点必须从**腰部**开始。第一版从地平线开始渐变，结果膝盖和小腿跟着一起晃。

## 组装阶段的两个坑

**逐帧居中会吃掉位移。** 摇摆版生成完丢进组装器，看着纹丝不动：组装器逐帧按 bbox 宽度居中，
摇摆把 bbox 撑宽、居中又把它抵消回去。修法是生成脚本最后把全套帧统一裁到**并集 bbox** 再存盘。

**每张关键帧要占等长格子。** 两张关键帧铺八格必须是 4+4。早期一律"一格一帧"，
于是 `A B A B A B A B`，每 200 ms 换一次姿势——看着像鬼畜抖动，不是呼吸。

## 验证方法（别靠眼睛看缩略图）

- **相邻帧差异**：算 `abs(frame[i] - frame[i+1]).mean()`，能抓出"A B A B"这种错位序列。
- **首尾差异**：闭合循环的最后一帧到第一帧，应该和普通相邻帧同一量级，不能突跳。
- **区域差异**：把画面切成"头 / 腰下 / 底 150 行"，分别算变化像素比例。下盘应该 <1%，
  头应该 15% 左右——这是判断"只有上半身在动"的硬指标。
- **坐标**：量成品图里头部质心的 x 均值，2~6 px 的位移在缩略图上根本看不出来。
